==============================================================================
1. Commands and keys                                *project-overview-usage*

  :ProjectOverview        Compact view
  :ProjectOverview!       Full view
  :ProjectOverviewAsk     Ask AI with the overview (needs the ask callback)
  :ProjectOverviewChat    Put the overview into chat (needs the chat callback)

Inside the window: q/<Esc> close, t toggle compact/full, r refresh,
gd jump to the file under the cursor.
Command names and keys can be overridden via setup; keys are not
registered by default.

==============================================================================
2. Configuration                                      *project-overview-config*

>lua
  require("project_overview").setup({
    keys = false,
    commands = { open = "ProjectOverview", ask = "ProjectOverviewAsk", chat = "ProjectOverviewChat" },
    buffer_scheme = "project-overview://",
    resolve_root = nil,
    ask = nil,
    chat = nil,
    digest_contract = nil, -- nil default; false off; string custom
    bridge_action = "project",
  })
<
==============================================================================
3. API                                                   *project-overview-api*

  open(opts)              { full?, root?, force? }
  digest(data, opts)      compact digest; opts.contract
  bridge(req)             { root?, path?, full?, wait_ms? } -> digest
  ask(opts) / chat(opts)  invoke the configured callbacks
  setup(opts)             register commands and keys
